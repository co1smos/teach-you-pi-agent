# Teach You Pi Agent — 跟着问题学习 Pi 源码

[English](README.md)

这个社区学习 fork 将一次 Pi 源码问答学习过程整理成可复用的练习册。它不是 Pi 官方课程，也不是另一个 Pi 实现。**M5** 沿用原学习模块的名称；不需要完成其他模块、访问私人项目，或读过原始对话。

## 选择文档

| 内容 | English | 中文 |
|---|---|---|
| 题目、提问协议、验收标准、空白问答记录 | [questions.md](docs/m5/questions.md) | [questions.zh-CN.md](docs/m5/questions.zh-CN.md) |
| 参考答案和源码依据（包含答案，请勿提前阅读） | [answers.md](docs/m5/answers.md) | [answers.zh-CN.md](docs/m5/answers.zh-CN.md) |

题目与参考答案分开，让你先独立阅读源码。你的**个人练习册副本**仍保留问答形式：每题通过后，依次记录学生的已通过答案、老师的标准答案和源码依据。公开模板不包含原学习者的回答或进度。

## 固定源码版本

源码固定在上游 commit [`a32782520f69cd81b54814c3a13df4c7bd1f3ad7`](https://github.com/earendil-works/pi/tree/a32782520f69cd81b54814c3a13df4c7bd1f3ad7)。本 fork 的 `main` 将完整的固定版本源码放在 `pi/`，学习文档放在外层。保留上游历史；fork 的 HEAD 不等于源码基线。不要切换到不断变化的上游 `main` 后仍假定行号一致。

```sh
git clone https://github.com/co1smos/teach-you-pi-agent.git
cd teach-you-pi-agent
git diff a32782520f69cd81b54814c3a13df4c7bd1f3ad7 HEAD:pi
```

最后一条命令应没有输出，表示pi/ 下整个源码目录与固定版本一致。只读源码无需安装依赖、构建、配置 API key 或付费调用模型；可选的 AI 老师可能有自己的使用成本。上游 [README](pi/README.md) 原样保留在 `pi/`。上游包命令应在 `pi/` 内运行，不是在本仓库根目录运行。依赖 Git 根目录的开发脚本与 CI 未适配此教学布局；上游工作流保留在 `pi/.github/`，不是生效的根目录工作流。

## 自学方式

1. 选中文或英文，将对应题目文档复制到仓库外的私人可写位置，例如 `../m5-progress.md`。源码路径始终相对于 教学仓库根目录（`pi/packages/...`），不是私人副本所在目录。
2. 阅读提问协议，按学习顺序开始第一题，先不打开参考答案。
3. 跟踪定义和调用者，用自己的话解释机制、职责、数据流及边界情况，并附文件和符号作为依据。必要时读出引用行号范围之外。
4. 完成尝试后，对照源码和当前题目的参考答案，自行修正直到满足 **95% 验收门槛**。这是定性的正确性标准，不是自动计算的分数。
5. 通过后，在私人副本中更新题目状态和该题问答记录：保留自己的答案，紧接着写标准答案，再写源码依据，然后进入下一题。

## 使用 AI 老师

选择能读取本地仓库的 coding assistant，提供下面的提示词，并填入你的私人练习册路径。无需 Pi 或 Hermes 专属功能。

```text
请使用当前仓库的 docs/m5/questions.zh-CN.md 教我学习 Pi。
我的私人可写进度练习册路径是：<我的副本的绝对路径>。
遵守练习册的提问协议与 95% 验收标准。
所有源码结论以 a32782520f69cd81b54814c3a13df4c7bd1f3ad7 为基线核实。
按板块顺序，每次只问一题；恢复时从第一个非 PASS 的问题继续。
通过前指出理解缺口，给出针对性的源码位置和启发式追问，不直接给出答案。
你可以私下查阅 docs/m5/answers.zh-CN.md 中当前题目的答案辅助评价；
通过前不要展示或近乎完整地复述它，参考答案与源码冲突时以源码为准。
通过后，在我的私人副本中同时更新题目状态和对应问答记录：
保留我的已通过答案的原话与语言，紧接着记录你的标准答案和源码依据。
即使切换教学语言，也只使用这个文件作为唯一进度记录。
不要修改 Pi 源码、公开模板或参考答案文件，不要公开我的个人回答。
现在请先说明板块、主题、Q 编号，再问第一个尚未通过的问题。
```

只要核心机制、职责边界或题目要求的关键情况仍有缺失，老师就应继续追问同一题；没有源码依据、只是“听起来合理”的答案不能通过。完整协议和评价维度在题目文档里，上面的启动提示词不能替代它们。

## 恢复与完成

新开会话时，重复提供同一启动提示词和同一个私人副本路径。从学习顺序中第一个非 PASS 的问题继续，不重做已通过题目。中英文只选**一个工作副本**作为进度来源，不并行维护两套状态。学生可用任一语言回答，记录时保留原话；附加翻译必须标注。

所有题目均通过，且都有学生答案、老师答案和源码依据，才算完成。仅仅读完参考答案不等于完成。私人练习册可能包含个人信息，如需公开应先自行检查。
